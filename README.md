# 👑 Golden Home — Luxury Cleaning Services Dubai
### 5-Star Hotel Standard Villa & Apartment Care

A high-converting, luxury web application tailored specifically for the Dubai, UAE market, matching the **Golden Home Premium Cleaning Service** brand identity (Emerald & Royal Gold with Ruby accents).

---

## 🌟 Tech Stack
- **Frontend**: React 19 + Tailwind CSS v4 + Lucide React + Vite
- **Backend**: Node.js + Express REST API (AED Pricing Engine & Booking Dispatch)
- **Styling**: Luxury Custom Glassmorphism, Micro-Animations, Gold Shimmer & Ambient Emerald Glow

---

## 🚀 How to Run

### 1. Frontend Dev Server (React + Vite):
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 2. Backend Server (Node.js + Express):
```bash
npm run server
```
Runs the API server on [http://localhost:5000](http://localhost:5000).

### 3. Production Build:
```bash
npm run build
```
Creates an optimized static bundle in the `dist/` directory.
